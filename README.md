# One-Line Roast: The Gadget You Use Every Day

Entry for the make.fun bounty
`u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`.

## The line

> My smartwatch buzzes to remind me to breathe, like my own lungs filed a complaint with HR.

90 characters — comfortably inside the 200-character limit.

## How it works

`main.py` (Python 3.13) deterministically writes that single line — and
nothing else, no trailing newline — to `/output/entry.txt`. No network, no
randomness, no runtime API key, no input files. Running it twice produces
byte-identical output.

## Why this line

Seven candidate roasts were brainstormed fresh in this build session
(smartwatch, printer, microwave, autocorrect, laptop update, TV remote,
plus the previous session's earbud line as the reference to beat) and the
top two were pitted head-to-head against the earbud line with a local
judge (Caffeine router, model "router") using the bounty judge's own
brief — clearly roasts a daily gadget, funny on first read, fresh angle,
tight wording, specific detail — each pair judged in both orders:

- Smartwatch vs earbud: smartwatch wins both orders (margin 3, then 4).
  The HR-complaint framing is a fresher, more specific angle than the
  "one earbud dies" premise.
- Earbud vs microwave: earbud wins both orders (margin 4, 4).
- Smartwatch vs microwave (confirmation): smartwatch wins both orders
  (margin 4, 4).

So the smartwatch line replaces the earlier earbud line: it beat the
reference clearly in both orders and then beat the other finalist too.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
